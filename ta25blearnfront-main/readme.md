# Ostunimekiri – olulisus ja sorteerimine

Täiendatud õpetaja `ta25blearnfront` projekt.

- Igal asjal on olulisus: kõrge, keskmine või madal.
- Uue asja lisamisel saab olulisuse valida.
- Kõik kolm nimekirja on `computed` abil olulisuse järgi sorteeritud.
- Kõrge olulisus on punane, keskmine kollane, madal roheline.
- Olemasolev tehtuks märkimine ja muud lehed on alles.

Käivitamine:
1. Ava projekt terminalis.
2. `bun install` (või `npm install`)
3. `bun run dev` (või `npm run dev`)
